# コタロの大格闘 Online（実験版） — Online Phase 10

> このフォルダは、完成版 Version 1.0 をコピーして作った **オンライン対戦の実験版** です。
> 公開中の Version 1.0 とは別物として扱います（Version 1.0 のゲーム部分のファイルは一切変更していません）。
> Online Phase 1 =「2つのブラウザを WebRTC でつなぐ通信実験」、Online Phase 2 =「GUEST がルミポを左右移動・ジャンプで操作する実験」。
> Online Phase 3 =「GUEST 側の予測（Client-side Prediction）で、自分のルミポがすぐ動くようにする実験」。
> Online Phase 4 =「通常攻撃『ぽよんアタック』1 種類だけをオンライン化（HOST が判定）」。
> Online Phase 5 =「GUEST のぽよんアタックに遅延補償（Lag Compensation）をかける実験」。
> Online Phase 6 =「コタロの必殺技『クラゲ電撃』1 種類をオンライン化（予測・HOST 判定・遅延補償）」。
> Online Phase 7 =「飛び道具『バブルショット』1 種類をオンライン化（HOST authoritative な Projectile 同期）」。
> Online Phase 8 =「既存のガードをオンライン化（押している状態を送り、成立は HOST が判定）」。
> Online Phase 9 =「KO・3 ストック・リスポーン・無敵・勝敗の同期（すべて HOST authoritative）」。1 試合を最後まで遊べる。
> Online Phase 10 =「READY → 3 / 2 / 1 / START! → 対戦 → 勝敗 → 再戦」を同じ接続のまま何試合でも続けられる。

## オンライン実験（Online Phase 1）
タイトル →「オンライン実験 TEST」→「ルームを作る」/「ルームに参加」

- ルームを作ると `KOTA-1234` のようなルームコードが表示されます。参加する側はその4桁を入力して「接続」。
- 接続後：Ping（1秒ごと）・平均Ping・最終受信からの時間・経路（直接／TURN中継）などの診断、
  LEFT / RIGHT / JUMP の通信テスト（PC は A / D / Space）、連続通信テスト（毎秒30回×10秒）、通信ログ（直近20件・コピー可）。
- URL に `?online`（または `#online`）を付けると、起動後すぐにオンライン実験画面を開きます（縦画面のスマホでも操作できます）。
- 開発用：`?stunonly` で PeerJS の TURN を使わない設定、`?netdebug` で PeerJS の詳細ログをコンソールへ。
- 通信は PeerJS 1.5.5（cdnjs から読み込み）と PeerJS の公開シグナリングサーバー（0.peerjs.com）を使います。詳しくは `docs/ONLINE_PHASE1.md`。

## 操作実験（Online Phase 2）
接続後、HOST の「操作実験を開始」で両方がゲーム画面へ。HOST = コタロ（いつもの操作）、GUEST = ルミポ（左右移動・ジャンプのみ）。
- GUEST の操作：PC は A / D・← / →、ジャンプは Space / W / ↑。スマホは画面下の LEFT / RIGHT / JUMP。
- HOST が正しい状態を決め（HOST authoritative）、GUEST へ 30Hz で位置などを送る。GUEST は 70ms 遅らせて補間表示（予測なし）。
- 「診断」で PING・入力 / 状態の Hz・番号・遅延の目安を表示。「実験を終了」で接続画面へ戻る。
- 詳しくは `docs/ONLINE_PHASE2.md`。

## 予測（Online Phase 3）
- GUEST の画面では、ルミポが入力した次のフレームから動く（予測）。正しい状態は今までどおり HOST が決め、ずれは自然に補正される。
- GUEST の「予測 ON / OFF」ボタン（または P キー）で、Phase 2 と同じ表示（予測なし）と切り替えて比べられる。URL に `?pred=off` で最初から OFF。
- 診断に予測誤差・補正回数・snap 回数・未確認入力数を表示。詳しくは `docs/ONLINE_PHASE3.md`。

## 攻撃（Online Phase 4）
- 操作実験中は両者ともぽよんアタック（J／スマホは「攻撃」ボタン）だけ使える。攻撃が出せるか・当たったか・ダメージ・吹っ飛びは HOST の既存処理が決める。
- GUEST の画面では押した瞬間に攻撃の見た目が出る（予測。当たり判定はしない）。命中は HOST から届いたものだけを表示。
- 診断に攻撃の受理・HIT/MISS・「見た目の当たり × HOST の判定」の比較・判定の瞬間の位置の差を表示。詳しくは `docs/ONLINE_PHASE4.md`。

## 遅延補償（Online Phase 5）
- GUEST のぽよんアタックだけ、HOST は「GUEST がその時見ていたコタロの位置（少し前の当たり判定）」で命中を判定する（最大 200ms 前まで）。ダメージ・吹っ飛びは今の状態に適用。HOST の攻撃は補償なし。
- GUEST は座標を送らず、HOST が発行した状態番号（と補間の位置）だけを送る。HOST が自分の履歴で検証する（不明な番号は補償なし）。
- HOST の「補償 ON / OFF」ボタン（または C キー）で切り替え。URL に `?lagcomp=off` で最初から OFF、`?lagmax=0〜300` で上限（ms）を変更（実験用）。
- 診断を開いている時だけ、HOST 画面に今のコタロ（水色）・判定に使った過去のコタロ（黄色の点線）・攻撃判定（赤）を表示。
- 診断に巻き戻し量（平均・中央値・最大）・上限到達・無効参照・「今の位置なら / 過去の位置なら」の比較・補償だけで当たった回数を表示。詳しくは `docs/ONLINE_PHASE5.md`。

## クラゲ電撃（Online Phase 6）
- 操作実験中は両者ともぽよんアタック（J）とクラゲ電撃（K／スマホは「必殺」ボタン）が使える。技の性能は Version 1.0 のまま（startup 9F・判定 10〜14F・全体 34F・13%・再使用待ち 0.7 秒）。
- 出せるか（再使用待ち・硬直・被弾中）・命中・ダメージ・吹っ飛び・ヒットストップは HOST の既存処理が決める。GUEST の画面では押した直後から溜めが見える（予測。命中は判定しない）。
- 遅延補償（ON・上限 200ms が通常）はクラゲ電撃にも同じ規則で働く。OFF は診断・比較用（HOST の C キー）。
- 診断は「ぽよん」「クラゲ電撃」の結果を技ごとの表で表示（スクリーンショット 1 枚で両方が分かる）。詳しくは `docs/ONLINE_PHASE6.md`。

## バブルショット（Online Phase 7）
- 操作実験中は両者とも泡（L／スマホは「泡」ボタン）も使える。性能は Version 1.0 のまま（8F 目に発射・速さ 540・寿命 1.5 秒・5%・同時 2 個まで）。
- 泡を出すか・移動・地形・寿命・命中・ダメージは HOST が決め、HOST が泡ごとの ID・位置を 30Hz の状態で、消えた時は消滅イベントで送る。
- GUEST の画面では自分の泡を予測で出し（見た目だけ）、HOST の泡が届いたら同じ泡として引き継ぐ。HOST で出なかった泡はすぐ薄く消える。
- 泡には遅延補償を使わない。詳しくは `docs/ONLINE_PHASE7.md`。

## ガード（Online Phase 8）
- 操作実験中は両者ともガード（I／スマホは「防御」ボタン）も使える。性能は Version 1.0 のまま（地上のみ・正面のみ・出始め 3F・硬直 10F・押し戻し 420）。
- GUEST は「押しているか」だけを送り、自分の画面では押した次のフレームからガードの姿勢が見える（予測）。防げたかは HOST が判定し、HIT と GUARD は攻撃ごとにどちらか 1 回だけ届く。
- ガード用の遅延補償・rollback はなし。詳しくは `docs/ONLINE_PHASE8.md`。

## KO・ストック・勝敗（Online Phase 9）
- 両者 3 ストック。場外 → ストック -1 → 約 1 秒後にリスポーン（ダメージ 0）→ 約 2 秒の無敵（点滅）。数値・場外ラインは Version 1.0 のまま。
- KO・ストック・リスポーン・無敵・勝者はすべて HOST が既存のルールで決め、KO ごとのイベントと 30Hz の状態で GUEST へ送る。GUEST は自分で決めない。
- どちらかのストックが 0 で試合終了（両画面に同じ「〇〇 WIN」）。同じステップで両者が最後のストックを失ったら「DRAW」。終了後は入力・泡・命中で状態は変わらない。
- 詳しくは `docs/ONLINE_PHASE9.md`。

## 試合の流れ・再戦（Online Phase 10）
- 接続後、接続画面で両方が「READY」を押すと試合開始（HOST / GUEST それぞれの READY / NOT READY を表示。片方だけでは始まらない）。
- 3 / 2 / 1 / START!（Version 1.0 のカウントダウン）。HOST が GO の時刻を決め、GUEST は Ping の時計のずれで表示をそろえる。START! までは両者とも操作できない。
- 勝敗表示で「もう一度」を両方が押すと次の試合（片方だけなら「相手を待っています…」）。「終了する」（または「実験を終了」）で接続画面へ。ページの再読み込み・再接続は不要。
- 詳しくは `docs/ONLINE_PHASE10.md`。

# （以下は Version 1.0 の説明）

# コタロの大格闘 — Version 1.0

海中のクラゲの世界で、コタロがCPU「ルミポ」と戦う 2D カジュアル対戦アクションです。
ブラウザで `index.html` を開けば遊べます（PC・スマートフォン横画面対応）。サーバーに置く場合は、このフォルダをそのまま公開してください。

## 遊び方
タイトル →「CPUと対戦」→ 難易度（EASY / NORMAL / HARD / CHALLENGE）→ 対戦 → 勝敗 →「もう一度」/「タイトルへ戻る」

| 操作 | PC | スマートフォン |
|---|---|---|
| 移動 | A / D（← / →） | 左スティック |
| ジャンプ（空中でもう1回） | Space | ジャンプ |
| ぽよんアタック | J | 攻撃 |
| クラゲ電撃 | K | 必殺 |
| バブルショット | L | 泡 |
| ガード（押している間） | I | 防御 |
| もう一度（対戦中） | R | — |

## 設定（src/config.js）
- `audio.master` / `audio.bgm` / `audio.se` … 全体・BGM・効果音の音量
- `audio.bgmFiles` … 正式な BGM ファイルのパス（置き方は `assets/audio/bgm/README.txt`）。未指定の間はゲーム内で合成するオリジナルの仮BGM（`audio.synthFallback`）
- `DEBUG_ENABLED` … 公開版は `false`。`true` にすると H キーで開発用表示（当たり判定・CPUの判断など）、T キーでタッチUIの切替

## 素材
- コタロさんの SD 画像（`assets/kotaro.png`）は許可を得て使用している素材です。加工・再生成はしていません。
- 背景・ステージ・ルミポ・エフェクトはすべてゲーム内の図形描画、効果音と仮BGMはゲーム内で合成した音です（外部の音源・画像は使っていません）。
