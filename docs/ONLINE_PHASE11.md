# コタロの大格闘 Online — Online Phase 11 完成報告（一般向けのオンライン対戦画面）

開発・検証用だったオンライン画面を、URL を開いたリスナーが説明なしで遊べる画面に整理した。
**ネットコード（接続・予測・補正・補間・遅延補償・命中判定・泡・ガード・状態の送信・KO・試合の番号・READY / カウントダウン / 再戦の同期）は変更していない。**
画面は既存の処理（`NetSession.host / join / close`、`OnlineMoveTest.setReady / requestRematch / end`）を呼ぶだけ。診断は削除せず「詳細」の中へ移した。

## 1. 導線
タイトル「オンライン対戦」→ オンライン対戦メニュー（ルームを作る / ルームに参加 / 戻る）→ ルームコード → 対戦相手を待つ → 接続 → 準備（READY）→
3 / 2 / 1 / START!（既存）→ 対戦 → 結果 →「再戦」（2 人とも押すと次の試合）または「退出」（オンライン対戦メニューへ）。

| 画面 | 表示 |
|---|---|
| メニュー | 「コタロの大格闘」「オンライン対戦」「2人用オンライン対戦」、ルームを作る / ルームに参加 / 戻る、短い遊び方 |
| ルームを作る | 「対戦相手を待っています…」、大きなルームコード（選択してコピーもできる）、「このコードを対戦相手に教えてください」、コピー、やめる |
| ルームに参加 | 「ルームコードを入力」、`KOTA-` の後に 4 桁、参加する。小文字・前後の空白・全角数字・`KOTA-` 付きも受け付ける（既存の `parseCode`）。4 桁でない時は例つきの案内 |
| 接続中 | 「接続しています…」/「対戦相手が参加しようとしています…」 |
| 接続後（READY） | 「対戦相手と接続しました！」、あなた（コタロ / ルミポ）・相手 の「準備中 / 準備OK」、状況の一文、大きな READY（押すと「準備を取り消す」）、退出 |
| 失敗 | 「接続できませんでした」＋一般向けの理由（例：ルームが見つかりません。ルームコードを確認して…）、「オンライン対戦メニューへ戻る」 |
| 対戦中 | 既存の HUD（ダメージ・ストック）と、上の中央に小さく「接続中」（0.5 秒以上届かない時は「通信が不安定」）・「詳細」・「退出」（2 回押し） |
| 結果 | 既存の「コタロ WIN / ルミポ WIN / DRAW」、自分から見た「あなたの勝ち！ / あなたの負け… / 引き分け」、再戦・退出、「対戦相手を待っています…」/「対戦相手が再戦を希望しています」 |
| 相手が退出 | 「対戦相手が退出しました」、「オンライン対戦メニューへ戻る」 |

画面に技術用語（PeerJS・WebRTC・HOST・GUEST・LagComp・予測・ICE・PING など）は出さない（「詳細」の中だけ）。

## 2. 退出
- 結果の「退出」・対戦中の「退出」・接続画面の「退出 / やめる」：既存の試合終了（`me`）→ 既存の `session.close`（相手へ `bye`）→ オンライン対戦メニュー。
- 相手側：既存の処理で接続画面に戻り、「対戦相手が退出しました」と「オンライン対戦メニューへ戻る」。
- 切断・失敗の理由の文言は一般向けに変更（例：`remote-bye` →「対戦相手が退出しました」）。理由の判定は変更なし。

## 3. 診断
- 対戦中：「詳細」で既存の診断（PING・fps・予測・補正・入力の待ち・押下の待ち・見た目の接触→HIT・巻き戻し・HIT/MISS・泡・ガード・KO・MATCH など）と、
  役割・予測 ON/OFF・LagComp ON/OFF のボタンを開く。「詳細を閉じる」で閉じる。毎試合、閉じた状態から。P / C キーは今までどおり。
- 接続画面：「詳細」で通信テスト・連続通信テスト・診断・通信ログ（コピー可）。
- 閉じている間も計測は今までどおり続く（表示しないだけ）。

## 7. 実機で次に確認すること
1. スマホ（縦・横）でルームコードの入力・コピー・READY・再戦・退出が押しやすいか。キーボードが出た時に入力欄が隠れないか。
2. 実際の PeerJS で、ルームが見つからない・回線の問題などの失敗時に一般向けの文言が出るか。
3. 相手が退出・ページを閉じた時に「対戦相手が退出しました / 接続が切れました」が出てメニューへ戻れるか。
4. 対戦中の「接続中 / 通信が不安定」の表示が実際の回線の状態と合っているか。
5. 「詳細」から診断を開いて、Phase 10.2 の計測値（見た目の接触→HIT・押下の待ち）が今までどおり見えるか。
