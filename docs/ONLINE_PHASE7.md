# コタロの大格闘 Online — Online Phase 7 完成報告

「バブルショットのオンライン同期」。発射後もゲーム世界を移動する Projectile を、HOST authoritative のまま初めて同期しました。
泡の性能（Version 1.0 のコード）は変更していません：L / スマホ「泡」、22F の技の 8F 目に発射、速さ 540、寿命 1.5 秒、5%・横 380 / 上 220、ヒットストップ 4F、
同時 2 個まで（`maxPerOwner`）、技の後に再使用待ち 0.3 秒、普通の地面に当たると消える（すり抜け足場は通過）。
Projectile 用の遅延補償・rollback・ガード・KO・勝敗・ルミポの調整は行っていません。今回は短時間の代表テストだけで終えています。

## 1. 仕組み
| 項目 | 内容 |
|---|---|
| 泡の入力 | 入力 `mi` に **`bp` = 泡を押した回数の累計**。増えた入力だけを「押した瞬間」として既存の `cmd.pressed.shoot` に。押しっぱなしでは増えない。座標・速度・HIT は送らない（GUEST からの偽の `pe` / `mh` は HOST が無視）。|
| 攻撃 ID | **押した入力の番号 × 4 + 技の種類**（0 ぽよん / 1 電撃 / 2 泡）。Phase 6 の ×2 を ×4 に広げただけ。|
| Projectile ID | HOST が既存の `spawnFrom` で泡が出た時に通し番号を付ける（泡ごとに一意）。泡は「出した技の攻撃 ID」も持つ。|
| HOST | 出せるか・発射・位置・向き・速さ・寿命・地形・命中・ダメージ・吹っ飛び・消滅はすべて既存の Fighter / ProjectileSystem / Combat。ProjectileSystem の `spawnFrom` / `removeDead` をこのインスタンスだけ包んで、ID 付けと消滅の記録をするだけ。|
| 状態同期 | 30Hz の HOST 状態に `b` = 場にある泡（最大 4 個）`[ID, 発射した側, x, y, 向き, 発射からのステップ数, 攻撃 ID]` を追加。消えた時は **消滅イベント `pe`**（ID・理由・位置・HOST 時刻）を 1 回だけ。消えた ID は GUEST で記録し、二度と表示しない（復活なし）。|
| 予測泡 | GUEST が L を押すと、予測のルミポが次のフレームから技を開始し、8F 目に予測泡を出す（既存と同じ位置・向き・同時 2 個まで・再使用待ちも HOST から同期）。予測泡は攻撃 ID で仮に識別し、**見た目だけ**（命中・消滅を決めない）。|
| 引継ぎ | HOST 状態に同じ攻撃 ID の泡が届いたら、その予測泡に Projectile ID を付けて**同じ泡として続ける**（2 個に見えない）。発射位置の差は表示上のずれとして 90ms で消す（120 以上・向きが違えば HOST に即座に合わせる）。|
| 発射拒否 | HOST でその技が出なかった / 8F を過ぎても泡が無い（同時 2 個・被弾など）/ 一定時間 HOST から確認が無い → 予測泡を 0.15 秒で薄く消す（弾ける演出・音なし）。溜め中に分かった時は、技の見た目も発射の前で止める。|
| 表示 | 自分の予測泡は予測のルミポと同じ「今」の時刻で、コタロの泡と予測していなかった泡はコタロと同じ補間の時刻（70ms 前）で、どちらも「発射位置 + 速さ × 時間」（既存と同じ式・ゆらぎも同じ）で毎フレーム計算して表示。30Hz のカクつきなし。描画は既存の泡の描き方そのまま。|
| 消滅 | 命中：HOST の命中イベント＋消滅イベントですぐ弾ける。地形・寿命：コタロの泡はコタロの表示の時刻が HOST の消えた時刻に来た時に弾ける。自分の予測泡は寿命・地形を見た目だけ先に終え、HOST の消滅イベントで記録を消す（二重に弾けない）。|
| 命中 | 既存の `Combat.resolve` が今の状態で判定（泡は遅延補償なし：Combat の中で攻撃側が泡の時は、近接用の過去 Hurtbox を使わない）。同じ泡で同じ相手に 2 回当たらないのは既存の `hitVictims`。命中イベント `mh` に Projectile ID を追加。|
| 音・演出 | 既存のもの（発射音 `bubbleFire`・泡粒、命中音 `hitLight`、弾ける `bubblePop`・`spawnBubblePop`）。GUEST は泡 1 個につき発射 1 回・弾ける 1 回（引き継いでも鳴らし直さない）。予測のルミポを進める間は音を止める仕組み（Phase 6）をそのまま使用。|
| 既存技 | ぽよん→泡・電撃→泡・泡→ぽよん・泡→電撃は v1.0 と同じ（技の途中では切り替わらず、終わり際の先行入力で次の技）。|

## 2. 代表テスト（短時間・人工遅延）
各条件 約 1 分の機能テスト（25 項目）：遠くへ発射→寿命、命中、地形（落下中に右の足場の側面）、連打 10 回、既存技との切替 4 通り、HOST の泡で GUEST が被弾、移動中・ジャンプ中の発射、偽の申告、泡が飛んでいる間の切断。

| 条件 | 実測 ping | 結果 | 予測泡 → HOST 泡の位置誤差（引継ぎ時）平均 / 最大 | 引継ぎ後の差 平均 / 最大 |
|---|---|---|---|---|
| A：ping 約 30ms | 37ms | **25/25** | 0.03 / 0.05 | 0.03 / 0.09 |
| B：ping 約 100ms | 111ms | **25/25** | 0.02 / 0.05 | 0.03 / 0.09 |
| C：揺らぎあり | 88ms | **25/25** | 0.02 / 0.05 | 0.03 / 0.09 |

- 各条件で：予測泡 11 → 引継ぎ 11・破棄 0・予測なし 0。1 発で 2 個に見えたことは 0 回。HOST の泡は最大 2 個（連打 10 回で 8 回拒否）、GUEST の画面も最大 2 個。
- 命中は両画面とも 5%・1 回、泡は両方から消える。地形・寿命でも両方から消える（理由も一致）。GUEST の音は 発射 1・命中音 1・弾ける 1。
- HOST の泡で GUEST が被弾：snap 0、往復 0、着地後に位置一致。
- L を押してから予測で技が始まるまで 約 5〜8ms（スマホのタッチで 8〜14ms）。
- 発射拒否（試験用に HOST だけ撃てない状態にした、ping 100ms）：3 回とも HOST は泡を出さず、GUEST の予測泡は自動で消えて残らない、弾ける音なし。ping 100ms では予測泡が一瞬（発射音つきで）見えてから薄く消える。
- 位置誤差がほぼ 0 なのは、GUEST の予測のルミポと HOST のルミポが同じ入力で同じ位置になり、泡の動きが「発射位置 + 速さ × 時間」で決まるため。ルミポの予測がずれた時（被弾直後など）は、その差がそのまま発射位置の差になり、上の仕組みで寄せます。

## 3. 通信量（代表テストの実測）
GUEST → HOST 約 4.7 KB/s、HOST → GUEST 約 6.3 KB/s（Phase 6：約 4.6 / 6.7〜6.8）。泡 1 個あたり状態に約 30 文字（最大 4 個）＋消える時に 1 回だけ消滅イベント。極端な増加なし。

## 4. スマホ
GUEST パッドに「泡」ボタン（必殺の左）。LEFT / RIGHT・JUMP・攻撃・必殺・泡が重ならず画面内。RIGHT＋泡（右向き）、LEFT＋JUMP＋泡（3 本指・空中・左向き）を確認。HOST のスマホは既存の「泡」ボタンが使える（ガードは非表示のまま）。

## 7. 既知事項
- Phase 6（クラゲ電撃）の遠隔実機テストは、テスト相手がいないため未実施。
- ルミポの復帰性能（対人では不利）は把握済み。変更していない。
- ping が大きい時、HOST で出なかった自分の泡が一瞬見えてから消えることがある（予測の限界）。
- 自分の泡は「今」、コタロは 70ms 前の時刻で表示しているため、自分の泡がコタロに重なって見えてから少し遅れて命中が出る（HOST が今の状態で判定。遅延補償なし）。

1. L（スマホ「泡」）を押した直後に技が始まり、8F 目に泡が出るか。発射音・弾ける音が 1 回ずつか。

4. 地形・寿命で両画面から消えるか。

7. ぽよん・電撃との切替が自然か。
8. 診断「バブル」の行：入力・発射・拒否・存在・生成計・命中・地形・寿命・引継ぎ・破棄・位置誤差。
